A deterministic Python program (standard library only, no network) that writes
one robot pickup line to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
